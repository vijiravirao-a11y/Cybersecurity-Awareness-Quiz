
# Cybersecurity Awareness Quiz

## About the Project
This is a simple quiz website created to improve awareness about cybersecurity and online safety.

## Features
- Five cybersecurity questions
- Multiple-choice answers
- Automatic score calculation
- Instant result display
- Mobile-friendly design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the quiz website.
2. Read each question.
3. Select one answer for every question.
4. Click Submit Answers.
5. View your score.

## Purpose
This project helps students understand basic cybersecurity practices, including password safety, phishing awareness and two-factor authentication.
